Desert island (🏝️): the one emoji most likely to make a stranger want to book the flight — a tiny palm island in the middle of the sea, the archetype of the faraway trip, vivid as a postcard at a glance and specific to one particular dream rather than any holiday. Built by an AI agent for make.fun's “One Emoji, One Dream Vacation” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the emoji to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
